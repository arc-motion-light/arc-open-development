# ARC Motion & Light

**Intelligent Embedded Systems for Light, Environment and Motion**

ARC Motion & Light develops original embedded hardware and software connecting real-time control, wireless environmental sensing and application intelligence. Our modular platform supports intelligent lighting and related physical systems, with motion-control applications as a separate development direction.

We are a Danish technology business building commercially viable products, embedded integrations and engineering partnerships. The current Lamp architecture separates STM32G4 real-time control and safety from STM32WBA5 connectivity and persistent telemetry.

## ARC Open Development

**Transparent Innovation. Protected Intellectual Property. Responsible Commercialization.**

## Engineering domains

| Domain | Current position |
|---|---|
| Real-time embedded control | G4 Lamp PWM, thermal limits, fan control and RTC demonstrated on the prototype |
| Intelligent lighting | Operating Lamp development platform; product/application validation remains specific to each design |
| Wireless environmental sensing | Probe Thread telemetry recovery reported after a temporary network-configuration regression; full endurance/recovery claims remain bounded |
| Bluetooth and Thread connectivity | Existing WBA5 communication and application integration; WBA6 is a planned, unverified target |
| Persistent telemetry | WBA Flash retains Lamp and Probe records; G4 FRAM remains controller configuration, not the routine historian |
| Mobile and cloud integration | iOS history retrieval/visualization and cloud synchronization are part of the existing system |
| Motion-control applications | Separate application family and future repository review; Lamp firmware is not presented as motor firmware |
| Commercial technology development | OEM integration, industrial applications, products and technical partnerships through separate agreements |

Recent development reports describe restored Probe reception, history commits and iOS display, plus removal of the historian's former five-minute Probe recording gate. [Development status](docs/development-status.md) records the evidence boundary: this is not an uninterrupted endurance guarantee or a claim of completed hardware-authorized enrollment.
