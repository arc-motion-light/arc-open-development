# Copyright and source-notice template

Apply notices only to ARC-owned files after provenance review. Replace `[verified year or range]` using actual file history; 2026 is an example for newly authored 2026 material, not a bulk replacement rule.

```c
/*
 * Copyright (c) [verified year or range] Juan-Antonio Søren Espinoza Pedersen
 * Trading as ARC Motion & Light
 *
 * SPDX-License-Identifier: PolyForm-Noncommercial-1.0.0
 *
 * Commercial licensing: juan@arcstore.io
 */
```

This header is for approved firmware licensing, not documentation or hardware. Do not overwrite vendor or contributor notices or represent a mixed file as wholly ARC-owned.

A future firmware copyright document should identify the legal holder, trading identity, scoped original paths, third-party exclusions, contributor arrangements and supported years. If a licensor supplies any `Required Notice:` lines, preserve them as the standard license requires. Do not insert ARC additions into the official license text.

## Original documentation attribution

For original ARC public documentation, identify **Copyright © 2026 Juan-Antonio Søren Espinoza Pedersen**, trading as ARC Motion & Light, Denmark, website https://arcstore.io, and SPDX `CC-BY-NC-4.0`. Include the official license link, retain supplied notices and identify changes. Use historical years appropriate to the document. This documentation notice does not license logos, executable tools, hardware or third-party material.
