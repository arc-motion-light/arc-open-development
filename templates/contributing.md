# Future firmware contribution policy template

Before using this template, resolve the contributor-rights decision in [the central policy](../CONTRIBUTING.md). Do not present a pending contributor agreement as signed or approved. Documentation licensing is approved separately as CC BY-NC 4.0; this does not transfer contributor ownership or automatically supply commercial relicensing rights.

```markdown
# Contributing

[Application-specific supported scope and technical prerequisites.]

Before submitting authored changes, contact maintainers to confirm the reviewed
contributor-rights arrangement. Contributors retain copyright unless an explicit
agreement says otherwise. A pull request alone does not transfer ownership or
give ARC commercial relicensing rights.

State target/board, source/version, behavior before and after the change, actual
tests and hardware limits. Preserve third-party notices. Do not submit secrets,
proprietary employer/vendor material or code without authority.

[Describe approved review, attribution and acceptance process.]
[Link conduct and private security reporting.]
```
