# Founder approval policy

ARC's founder approves the exact candidate for each repository release. Licensing decisions, preparation and technical builds do not automatically authorize GitHub creation, pushes, visibility changes or live organization settings updates.

## Material decisions

- Original ARC public documentation uses approved CC BY-NC 4.0 with the scope in [LICENSING](../LICENSING.md).
- ARC-owned firmware has the selected PolyForm Noncommercial 1.0.0 policy, subject to independent ownership and dependency review.
- The existing official ARC logo is designated for ARC presentation; branding rights remain reserved.
- Contributor-rights arrangements, executable tooling and hardware licensing require their own decisions.

## Private approval record

Record the approver, actual decision date, exact repository/commit, covered material, unresolved findings and explicitly authorized publication actions privately. Separate approval is needed for a live organization-avatar change. Central documentation approval does not approve every future firmware distribution or execute an IP transfer.

Before publishing, review the proposed Git history as well as its current tree. Removing an internal report from the latest commit does not remove earlier committed copies. A sanitized distribution or separately approved history cleanup must exclude material intended to remain private while preserving original provenance privately.

[Current development status](../docs/development-status.md) describes technical evidence and limits. Follow the licensing, security and release checklists and update publication states only after the corresponding action occurs.
