# Repository portfolio

[The registry](repository-registry.md) records proposed names, responsibilities, publication state and technical maturity separately. Names are reservations in this plan, not assertions that public repositories exist.

[Naming conventions](naming-conventions.md) keep application and MCU-family boundaries clear. [Publication policy](publication-policy.md) defines transitions and approval. Existing firmware trees and Git histories remain where they are; Phase 1 creates only this independent documentation repository.
