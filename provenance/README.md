# Development provenance

[Development history](development-history.md) contains bounded, evidence-supported milestones. [The policy](provenance-policy.md) defines source and authorship preservation. [Release evidence](release-evidence.md) specifies the record required for an actual distribution.

Original development records remain private and untouched. No source archive, raw debug dump, device identifier, commissioning secret or confidential investor document is copied into this foundation. Safe summaries are not substitutes for retaining original evidence.
