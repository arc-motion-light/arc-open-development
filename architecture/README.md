# Platform architecture

[Platform overview](platform-overview.md) establishes component ownership. [Embedded control](embedded-control.md) covers G4 safety and execution; [wireless connectivity](wireless-connectivity.md) covers WBA and network recovery; [telemetry and data](telemetry-and-data.md) covers recording and synchronization; [hardware abstraction](hardware-abstraction.md) sets target-specific compatibility rules.

These documents describe the existing Lamp development architecture and intended reusable boundaries. They do not require motion, Probe or remote applications to share the Lamp firmware or its safety assumptions.
