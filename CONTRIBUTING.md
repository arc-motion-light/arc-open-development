# Collaboration and interim contributor rights

ARC welcomes documentation feedback, issue reports, engineering discussion, technical proposals and research collaboration. Read [development status](docs/development-status.md), [the conduct policy](CODE_OF_CONDUCT.md) and [private security reporting](SECURITY.md) before sharing material.

Participation is not assignment of intellectual property. A pull request, issue comment or public license does not automatically transfer contributor copyright to ARC. Do not submit secrets, personal data, confidential employer material or vendor code without authority.

## Interim acceptance policy

Substantive externally authored code or documentation requires explicit maintainer/founder approval of its rights before acceptance. Significant third-party code contributions must not be merged while the contributor-rights arrangement is unresolved. Feedback and discussion can proceed without assuming ownership of authored material or adopting it into a release.

Original ARC documentation uses CC BY-NC 4.0; original ARC firmware has the separately selected PolyForm policy. Neither alone necessarily grants ARC the commercial relicensing rights it may need in an external contribution. A reviewed Contributor License Agreement may be appropriate: it can preserve contributor ownership while expressly granting the required distribution and commercial licensing rights. Assignment is a separate alternative, not presumed policy. A provenance sign-off alone does not resolve relicensing authority.

No complicated CLA or assignment contract is created or deemed signed in Phase 1B. Record contributor identity/authority, origin, applicable license, required commercial rights and attribution before accepting authored changes. A future approved process must explain the rights plainly.

Technical proposals should identify target, expected behavior, actual tests, limitations and effects on control/safety/persistence. Repository publication remains a separate [founder-approved decision](publication/founder-approval.md); documentation reuse already permitted by its license does not depend on that decision.
