# Product and application families

These pages describe development responsibilities and intended use, not purchasing availability or certification.

- [Lamp](lamp.md): demonstrated real-time controller and connected historian prototype.
- [Wireless Probe](wireless-probe.md): environmental sensing, reported restored telemetry and separate unfinished durable onboarding work.
- [Motor control](motor-control.md): independent motion application direction.
- [Gateway](gateway.md): standalone connectivity application, requiring its own source/publication audit.
- [Remote controller](remote-controller.md): planned battery/touch application on the WBA platform.

Check [development status](../docs/development-status.md) and [the proposed repository registry](../repositories/repository-registry.md) before treating a family as a released product.
